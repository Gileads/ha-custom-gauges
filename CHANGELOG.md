# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

## [1.0.0] - 2026-10-07

### Ajout
- **Half Arc Gauge** (`custom:half-arc-gauge`)
  - Jauge en demi-arc avec styles modernes
  - Support de 0–4 mini-valeurs
  - Éditeur visuel intégré
  - Responsive design

- **Battery Ring Gauge** (`custom:battery-ring-gauge`)
  - Jauge circulaire style Garmin
  - Module responsive intégré
  - Support de `layout_align`
  - Tri automatique des entités

- **Jauge Aiguille Puissance** (`custom:jauge-aiguille-puissance`)
  - Jauge rétro avec aiguille analogique
  - Affichage digital des watts
  - Visuels détaillés (cerclage, vis, zone rouge)
  - Support des polices Google

- **Jauge Thermo Hygro** (`custom:jauge-thermo-hygro`)
  - Double aiguille température + humidité
  - Style instrument météo ancien
  - ~60+ paramètres de personnalisation
  - Support `card_transparent`

- **Module Card Transparent**
  - Paramètre `card_transparent` pour tous les fonds
  - Patch visuel automatique

### Initial Release
- Publication initiale du pack HACS (fichier unique dist/ha-custom-gauges.js)
